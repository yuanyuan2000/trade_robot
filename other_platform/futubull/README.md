# 富途牛牛自编指标与策略回测

本目录包含与项目标准指标公式一致的富途牛牛 Python 自编指标：

- `relative_atr.py`：相对 ATR（RATR），默认窗口 `N=13`；
- `wtme.py`：加权真实波幅动量效率，默认窗口 `N=13`、半衰期 `h=6`，`epsilon` 固定为 `1e-8`。

同时包含四份可直接粘贴到富途“代码策略”的回测策略：

- `rapid_drop_ratr_rotation.py`：急跌回避与 RATR 动量轮动；
- `rapid_drop_wtme_rotation.py`：急跌回避与 WTME 动量轮动；
- `rapid_drop_wtme_rotation_v2.py`：对应项目 WTME 2.0.0，并加入当前参数与 VOLAT 动态杠杆
  的 1/5 现金仓位映射；旧版文件继续保留；
- `sevenstar_etf_rotation.py`：七星 ETF 轮动。

## 导入方式

### 自编指标

在富途牛牛桌面端进入 K 线图的“指标管理”，新建 **Python** 自编指标，
将对应文件的完整代码粘贴到编辑器后测试并应用。两个指标都应放在副图。

富途 Python 指标支持 `input_parameter(title, default)`。因此本实现保留了用户
要求的参数：RATR 可调整窗口长度，WTME 可调整窗口长度和半衰期。参数建议范围为：

- RATR 窗口：`1` 到 `500` 的整数；
- WTME 窗口：`2` 到 `500` 的整数；
- WTME 半衰期：`0.1` 到 `500`。

富途的参数面板目前由 `input_parameter` 的标题和默认值生成，脚本本身不能声明
最小值或最大值。输入无效参数时，本实现返回空值序列。

脚本刻意没有使用生成器表达式、列表推导式或跨行布尔条件。虽然这些写法属于标准
Python，部分富途客户端版本的编辑器解析器仍可能误报语法错误；这里使用显式循环和
单行条件来兼容该解析器。

### 策略回测

1. 在富途牛牛量化功能中创建 **Python 代码策略**，把四份策略文件中的其中一份完整
   粘贴进去；每份文件都是独立策略，不能把多份代码合并到同一个编辑器中。
2. 运行标的按下表绑定。候选顺序会影响七星同分时的稳定决胜顺序。
3. 将策略触发方式设为 **每根 1 分钟 K 线运行一次**。多运行标的会在同一分钟产生多次
   回调，代码内的日期/时刻保护会确保每个事件每天只执行一次。
4. 使用常规交易时段数据；默认时刻按 `TimeZone.ET`（美国东部时间）解释。
5. 先用较短区间检查订单日志和目标切换，再扩大回测区间。

代码策略文件必须直接从 `class Strategy(StrategyBase)` 开始。富途会把模块级文档字符串、
`import math` 等类外语句判定为不在约定函数内，因此四份策略均不包含模块级导入；所需的
对数和幂运算分别使用富途内置 `math_log()` 与 `power()`。

| 文件 | 候选运行标的默认绑定 | 额外运行标的 |
| --- | --- | --- |
| `rapid_drop_ratr_rotation.py` | SPY、GLD、NVDA、MU、XLE | 无 |
| `rapid_drop_wtme_rotation.py` | GLD、SLV、XLE、SPY、QQQ、SOXX、FXI、第 8 个自定 | 无 |
| `rapid_drop_wtme_rotation_v2.py` | GLD、SLV、XLE、SPY、QQQ、SOXX、DRAM、FXI | 无 |
| `sevenstar_etf_rotation.py` | GLD、USO、SPY、QQQ、DIA、IWM、TLT | BIL（防御标的） |

所有运行标的都使用 `declare_trig_symbol(is_trade_symbol=True)`，所以在启动回测时从富途
参数面板绑定真实证券；文件里没有把代码写死。三份策略也通过 `show_variable` 保留了
项目中的数值和布尔参数。富途只提供浮点、整数、布尔三类外显变量，因此选择项改用整数：

- RATR `atr_weighting_mode`：`1=Wilder`、`2=EMA`、`3=线性加权`、`4=简单平均`；
- 七星 `trend_formula_mode`：`1=consistent_w2`、`2=legacy_v1`。

时间参数拆成 `*_hour` 与 `*_minute`。策略不会在缺失指定分钟时延后补跑，以免用更晚
行情污染原决策时点；请确保回测触发频率覆盖 09:40、09:50、10:00、11:00、14:00 和 14:01。

## 策略逻辑对应关系

### 急跌回避与 RATR

- 09:40 使用此前最后一根完整 1 分钟 K 线收盘价检查最近 3 个单日变化段；
- 百分比急跌默认开启（`<= -5%`），ATR 急跌默认关闭（启用后为 `<= -2 ATR`）；
- 10:00 计算 `(当前决策价 - 5 个交易日前收盘价) / 截至昨日的 ATR(5)`；
- 排除当日急跌标的，按分数降序、代码升序取前 `holdings_num` 只；
- 总目标仓位默认 100% 等权。已经持有且仍是目标时不做日常重复再平衡。

递推 ATR 默认读取最多 250 根完整日线预热，`atr_warmup_sessions` 可调；简单与线性模式
虽然只需要固定窗口，仍共用同一历史读取函数。富途单次 `select` 最大为 500，因此代码
把完整日线回看安全限制为 499 根。

### 急跌回避与 WTME

- 09:50 执行与项目一致的百分比单日急跌过滤；
- 10:00 使用此前 `N` 根完整日线和当前决策价组成 `N` 个观测；
- 当前观测固定为“昨日收盘到当前决策价”，其 TR 为两者差的绝对值，不读取当天未来
  才能确定的最高价或最低价；
- 默认 `N=13`、半衰期 `h=6`、`epsilon=1e-8`，选择 8 个候选中 WTME 最高的未过滤标的；
- 分数完全相同时按代码升序决定；目标未变时不重复再平衡。

WTME 策略与本目录行情副图指标现在均默认使用 `13/6`；策略参数仍可在富途回测参数面板
手动修改。

WTME V2 固定复现项目当前实际保存配置：`N=13 / h=6`、急跌回看 5 段且阈值 5%、09:50
风险检查、10:00 选择、排名前 1 且评分严格大于 `-15` 两项同时满足、最多持有 1 只、等权
分配；VOLAT 动态杠杆参数为 `15 / 10 / 40% / 5x`，且不因倍率单独变化自动再平衡。代码仍
保留四种分配模式与上涨卖出保护能力，但这两项在当前配置中分别为等权和关闭。富途代码策略
没有项目式逐标的动态杠杆层，
所以目标仓位统一为“项目目标 × 策略特殊杠杆 × 动态杠杆 ÷ 5”：1.0 倍对应 20%，5.0 倍
对应 100%；关闭动态杠杆时也保留 1/5 降级。动态倍率以 0.1 倍向下取整，是否只因倍率变化
再平衡由 `rebalance_on_dynamic_leverage_change` 控制，默认关闭。

### 七星 ETF 轮动

- 11:00 独立检查全部候选持仓和 BIL 的历史高点回撤保护；
- 14:00 用此前 25 个完整日线收盘和 13:59 完整分钟收盘计算加权对数趋势、R² 和评分，
  依次应用高点回撤、放量过热、短动量、近三段急跌、非正趋势和评分开区间过滤；
- 14:00 缓存排名并先卖非目标，14:01 复用缓存、重新检查高点回撤后再买；
- 没有合格候选时转入 BIL；有多个目标时等权，目标金额偏差不超过 5% 时不调整；
- 一致公式与历史 `legacy_v1` 公式均已保留，默认使用项目当前的 `consistent_w2`。

富途日线 `select=1` 是正在形成的当日日线，因此七星的当日累计量直接取其盘中成交量；
全部历史价格、高低价和历史成交量只从 `select=2` 开始读取。代码还为每个运行标的保留了
不会执行的 `_data_prepare_hints()`，用途是让富途回测器静态识别动态循环所需的最大历史
窗口，不能删除。

## 平台边界

- 三份代码按项目正式的美股默认池和美国东部时间编写。若改成港股或沪深标的，需要同步
  修改 `TimeZone.ET`、事件时刻和交易方式，不能只替换证券代码。
- 策略用市价单复刻项目“信号分钟之后成交”的行为。富途帮助中心明确提示 A 股通不支持
  市价单，因此这些文件不能原样用于 A 股通交易。
- 项目引擎会把七星 14:00/14:01 在美股提前收市日映射为收市前 2/1 分钟；富途代码接口
  没有直接暴露项目所用的交易日历映射，本实现保持固定时刻，提前收市日不会执行这两个
  事件。这是已知的平台差异。
- 费用、滑点、整手、购买力、停牌和实际成交由富途回测设置与撮合器处理，结果不会与项目
  自带撮合器逐笔完全相同；信号公式、无未来数据边界、过滤顺序、排名和持仓目标保持一致。
- 富途回测的历史 tick 是用 1 分钟 K 线模拟的。这里建议使用每根 1 分钟 K 线触发，避免
  把同一分钟内模拟 tick 的先后顺序误当成真实逐笔成交。

## 公式口径

RATR 不是“ATR 除以价格”，而是：

```text
(当前收盘价 - N 个周期前收盘价) / 前一周期 Wilder ATR(N)
```

分母排除当前 K 线，以匹配项目的实时无未来数据口径。它不同于富途内置 ATR；
富途内置 ATR 使用 TR 的简单移动平均，本实现则按项目要求自行计算 Wilder ATR。

WTME 对最近 `N` 个普通收益率和标准化真实波幅使用指数半衰权重：

```text
r_i  = (C_i - C_(i-1)) / C_(i-1)
TR_i = max(H_i-L_i, abs(H_i-C_(i-1)), abs(L_i-C_(i-1)))
a_i  = TR_i / C_(i-1)
q_i  = 2 ** (-(N-i)/h)
w_i  = q_i / sum(q)
WTME = 100 * sum(w_i*r_i) / (sum(w_i*a_i) + 1e-8)
```

当前尚未收线的 K 线也会参与最新值计算，因此盘中最新值会随最高价、最低价和
收盘价变化；历史已收线 K 线不受此影响。
