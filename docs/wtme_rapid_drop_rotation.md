# WTME 指标与急跌回避轮动策略

本文说明项目内置的“加权真实波幅动量效率”（Weighted True Range Momentum Efficiency，WTME）指标，以及“急跌回避与 WTME 动量轮动”代码策略。本文是正式实现文档；根目录的 `new_indicator.md` 仅作为需求来源，运行逻辑不依赖该临时文件。

## 一、WTME 指标

### 1. 目标与取值

WTME 衡量近期加权方向收益相对于同期真实波动空间的比例：

- 上涨动量为正，下跌动量为负；
- 越新的观测权重越高；
- 方向越一致、真实波动越小，绝对得分越高；
- 收益率与真实波幅都按价格标准化，可横向比较不同价格水平的标的；
- 使用普通收益率时，理论上通常位于 `[-100, 100]`；`epsilon` 会让绝对值略小于 100。

### 2. 输入与公式

对最近 `N` 个收益/真实波幅观测，需要 `N+1` 根 OHLC K 线。第 `i` 个观测使用当前 K 线 `C_i、H_i、L_i` 和前一根收盘价 `C_(i-1)`：

```text
r_i  = (C_i - C_(i-1)) / C_(i-1)

TR_i = max(
  H_i - L_i,
  abs(H_i - C_(i-1)),
  abs(L_i - C_(i-1))
)

a_i = TR_i / C_(i-1)
```

半衰期为 `h` 时，最旧到最新的原始权重与归一化权重为：

```text
q_i = 2 ^ (-(N-i)/h), i = 1..N
w_i = q_i / sum(q)
```

因此最新观测的 `q_N=1`，向前 `h` 个观测的权重为其一半。最终指标为：

```text
R_w  = sum(w_i * r_i)
A_w  = sum(w_i * a_i)
WTME = 100 * R_w / (A_w + epsilon)
```

实现使用普通百分比收益率，不使用对数收益率。若任一前收盘价小于等于零、参数无效或历史不足，当前值为不可计算。

### 3. 参数

| 参数 | 指标系统字段 | 默认值 | 有效范围 | 说明 |
| --- | --- | ---: | ---: | --- |
| 窗口 `N` | `period` | 40 | 2–500 | 收益与 TR 观测数量 |
| 半衰期 `h` | `half_life` | 15 | 0.1–500 | 越小越强调近期变化 |
| 防除零项 | `epsilon` | `1e-8` | `1e-12–0.01` | 加在 `A_w` 后；通常不应调大 |

内置收藏配置为 `WTME40(h=15)`。行情页可以创建其他参数组合，并可将 WTME 显示在 K 线下方的振荡指标区域或行情总览自定义指标列中。

### 4. 数据边界

标准 WTME 对传入的每根 K 线采用同一固定公式。第一个有效值位于序列下标 `N`，因为
`N` 个观测需要 `N+1` 根 K 线。若行情输入包含一根尚未收线的 K 线，系统也使用截至当前
已经记录的 `H/L/C` 计算最新暂定值，并通过 `is_provisional=true`、`as_of` 和 `price_basis`
明确标识；随着盘中 OHLC 更新，该值可以变化。行情总览标准指标固定使用基于本地已存公司
行动的前复权日线，详情指标使用用户当前选择的前复权、仅拆股复权或原始 K 线。

“标准指标公式固定”不限制策略的输入自由。策略可以只输入完成日线、以某个决策价构造
当前观测，或采用其他不含未来信息的设计；此时得到的是策略值，不是行情页标准 K 线值。

## 二、急跌回避与 WTME 动量轮动策略

### 1. 策略标识

```text
code_key: rapid_drop_wtme_rotation
version: 1.1.0
selection_mode: competition
```

该策略是原急跌回避轮动思路的 WTME 版本：保留百分比单日急跌过滤，使用 WTME 进行横截面评分，最终只选择一只评分最高的未过滤标的。策略没有 ATR 周期、ATR 平滑或 ATR 权重参数。

### 2. 每日执行顺序

1. 在 `risk_check_time` 对全部候选标的执行急跌检查。
2. 命中任一已启用规则的标的加入当日过滤集合；若当前持有则立即生成清仓目标。
3. 在 `selection_time` 为所有标的计算 WTME，并从未过滤标的中按“分数降序、代码升序”确定唯一目标。代码升序只用于分数完全相同的确定性决胜。
4. 清仓非目标持仓；目标为空时保持现金。
5. 目标未持有时，以 `target_weight` 买入。目标与现有持仓相同则不做日常重复再平衡。

风险检查时间必须严格早于评分时间。

### 3. 急跌过滤

策略检查最近 `drop_lookback_sessions` 个单日变化段，其中最后一段为“前一日收盘价 → 风险检查时点价格”。该百分比过滤可以关闭。

百分比规则：

```text
change = current_price / previous_close - 1
过滤条件：change <= -drop_threshold_percent / 100
```

这里不计算 ATR。风险过滤只使用上述单日百分比变化；WTME 分母则始终按第 1 节定义，直接对每日 `a_i=TR_i/C_(i-1)` 使用 WTME 半衰期权重。

### 4. 评分时点与无未来数据口径

盘中评分时，当天日线尚未完成，不能使用当天最终最高价、最低价或收盘价。策略使用以下点时可知口径：

- 历史观测使用评分日之前的完整日线；
- 当前观测的 `close` 使用 `selection_time` 的决策价格；
- 当前观测的 `high=max(前收盘价, 决策价)`；
- 当前观测的 `low=min(前收盘价, 决策价)`；
- 因而当前观测的 `TR=abs(决策价-前收盘价)`，是截至该时点真实波幅的保守下界；
- 历史 `N-1` 个观测加当前观测，共组成 `N` 个 WTME 观测。

这一约定使评分及时反映当前价格，又不会在回测中偷看当天之后才知道的高低价。它与完整日线 WTME 的数值可能不同：若当天盘中曾出现更大振幅，实际完整日线的分母会更大、绝对评分通常会更低。

### 5. 策略参数

| 参数 | 默认值 | 说明 |
| --- | ---: | --- |
| `wtme_period` | 40 | WTME 窗口 `N` |
| `wtme_half_life` | 15 | WTME 半衰期 `h` |
| `wtme_epsilon` | `1e-8` | WTME 防除零项 |
| `enable_percent_drop_filter` | 开启 | 启用百分比急跌过滤 |
| `drop_threshold_percent` | 5% | 百分比急跌阈值 |
| `drop_lookback_sessions` | 3 | 急跌观察交易日 |
| `risk_check_time` | 09:40 | 急跌检查时间（纽约时间） |
| `selection_time` | 10:00 | WTME 评分与轮动时间（纽约时间） |
| `target_weight` | 100% | 唯一目标标的仓位 |

策略最小历史需求取 WTME 窗口和百分比急跌观察期两者需求的最大值。

### 6. 审计日志

风险检查写入 `RAPID_DROP_WTME_RISK_CHECK`；WTME 评分写入 `RAPID_DROP_WTME_DAILY_SCORE`。每个评分日志至少包含：

- `score`、`weighted_return`、`weighted_true_range`；
- 当前决策价、前收盘价和当前观测 TR；
- `current_observation_is_partial=true`；
- 急跌过滤代码与原因；
- 合格排名及是否成为目标。

回测导出会把这些结构化记录放入“策略自定义日志”工作表，实时决策邮件会列出 WTME 评分摘要。
实时任务详情的观察面板会对行情总览全部标的展示 `Rw`、`Aw`、WTME 评分、过滤原因、
面板排名和目标。这里显示的是“策略加权收益/策略加权波幅/策略 WTME 评分”：面板把内部
数据库最新价格代入本策略上述盘中观测构造，模拟当前时点的策略计算，并非行情页标准 WTME，
也不是最近一次正式决策。该面板不调用外部 API；正式事件仍只处理任务候选池并独立取得
IEX 快照。行情总览与正式事件的 SIP/IEX 来源本阶段不强制统一。

## 三、验证范围

自动化测试覆盖：

- 指数半衰权重和手工公式逐项一致；
- 权重和为 1，距离半衰期的权重关系正确；
- 平稳上涨接近高正分、平稳下跌接近高负分；
- 上下震荡的绝对评分明显低于平稳单向走势；
- OHLC 按同一倍数缩放后评分不变；
- 指标参数校验、页面入口和行情总览计算链路；
- 代码策略参数、执行事件、急跌过滤、未过滤排名和实际买入；
- 使用完整回测引擎成功生成 WTME 策略交易与审计日志。

WTME 只衡量方向效率，不代表未来收益，也不直接限制估值、流动性、跳空风险或组合集中度。默认参数是起始配置，部署前仍应针对实际候选池、成本和回测区间做稳健性验证。
