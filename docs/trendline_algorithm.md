# 智能直线趋势线算法

本文按程序实际执行顺序说明当前趋势线算法。生产实现位于
`services/trendline_analysis_service.py`，算法版本为
`trendline-v11-trend-families-2`。

## 1. 算法要解决什么问题

算法读取最新 N 根 K 线，默认 N=150，寻找两类肉眼可见的单侧边界：

- 上涨趋势下方的支撑线，斜率必须大于 0；
- 下跌趋势上方的压力线，斜率必须小于 0。

它不是穿过所有收盘价的线性回归线。上涨时价格可以长时间远离下方支撑线，
但回调低点应多次靠近支撑；下跌压力线完全对称。

算法对当前完整窗口作一次回看式视觉识别。因此，图上较早的线段可能利用了窗口内
较晚出现的 K 线。这符合“解释最新 150 根 K 线”的用途，但不能直接把今天识别出的
历史线用于交易回测。回测必须在每个历史日期截断数据后另行运行。

支持的 K 线周期是 `1D`、`3D`、`1W`、`1M`。成交量随 K 线保留，但目前不参与评分。

## 2. 读取和标准化价格

### 2.1 ATR

先计算真实波幅：

```text
TR = max(
    High - Low,
    abs(High - PreviousClose),
    abs(Low - PreviousClose)
)
```

再取最近 14 根 TR 的滚动中位数。这里虽然沿用 ATR 这个名称，但不是 Wilder ATR。
使用中位数是为了降低单日异常波动的影响。

后续距离都除以当地 ATR。例如 `0.5 ATR` 表示半个近期典型波幅，与资产价格单位无关。

| 参数 | 当前值 | 含义 |
| --- | ---: | --- |
| ATR 窗口 | 14 | 越大越平稳，但对波动变化反应越慢 |
| `min_periods` | 2 | 至少有 2 根 TR 后开始计算 |
| 除法下限 | `1e-9` | 防止 ATR 为零造成除零 |

### 2.2 趋势锚点

支撑线和压力线拟合使用“实体为主、影线为辅”的锚点：

```text
上涨支撑：
body_edge = min(Open, Close)
wick_mid  = (Low + body_edge) / 2
anchor_up = 0.75 * body_edge + 0.25 * wick_mid

下跌压力：
body_edge   = max(Open, Close)
wick_mid    = (High + body_edge) / 2
anchor_down = 0.75 * body_edge + 0.25 * wick_mid
```

实体权重 0.75 让影线可以轻微穿线，又不会完全忽略长影线表达的支撑或压力。
该锚点只用于拟合和结构触点；最新趋势状态改用收盘价判断，避免开盘价掩盖当天收盘结果。

## 3. 生成候选时间窗口

算法不会穷举所有起止日期，而是先粗搜再精搜。

N=150 时主要粗搜长度约为：

```text
7, 10, 15, 22, 32, 45, 59, 63, 86, 116, 150
```

短窗口结束日期逐根移动，中期约每 2 根移动，长期约每 3 根移动。粗搜后：

1. 保留全局最高的一批候选；
2. 按方向、层级、起点所在五分区、终点所在五分区分别保留局部强线；
3. 对强候选起止位置在约正负 6 根范围内精搜；
4. 对最新短期结构额外搜索最近 10 个结束位置。

这样既能找到当前趋势，也不会让近期强波段挤掉窗口前部清晰的历史结构。

| 参数 | 当前值 | 含义 |
| --- | ---: | --- |
| 最短拟合长度 | 7 根 | 更短的线太容易过拟合 |
| 斜率抽样点上限 | 28 | 控制两两斜率计算量 |
| 全局粗候选 | 36 | 首轮直接保留的高分线数量 |
| 每个时空分组保留 | 2 | 保证不同图表区域都有机会 |
| 精搜起止偏移 | 约 ±6 根 | 修正粗搜索的日期误差 |
| 最新短线终点范围 | 最近 10 根 | 短期线必须具有现实相关性 |

## 4. 在每个窗口中拟合直线

候选线公式：

```text
line(i) = intercept + slope * i
```

上涨只保留正斜率，下跌只保留负斜率。程序从抽样锚点的两两斜率中取
8% 到 92% 的 15 个分位点，再尝试 3%、7%、13%、20% 四档单侧截距。
下跌线使用对称的高分位截距。

每个窗口先用以下廉价指标粗评：

- 锚点位于正确一侧的覆盖率；
- 锚点到线的低分位距离；
- 严重穿线比例；
- 实体完整性。

只对前 5 个斜率和截距组合执行完整触点识别。这样不会改变评分含义，只减少重复计算。

## 5. 计算候选线与价格的距离

统一方向距离：

```text
d = 1  （上涨支撑）
d = -1 （下跌压力）

gap = d * (anchor - line) / ATR
```

- `gap > 0`：价格在趋势线正确一侧；
- `gap = 0`：刚好在线上；
- `gap < 0`：价格穿到趋势线错误一侧。

覆盖率允许 `-0.22 ATR` 的小幅穿线。完整性从 72% 覆盖率开始获得分数，
到约 99% 接近满分；软穿线深度和低于 `-0.80 ATR` 的严重穿线会继续减分。

实体使用独立距离：

```text
body_gap = d * (body_edge - line) / ATR
```

| 参数 | 当前值 | 含义 |
| --- | ---: | --- |
| 允许的小幅锚点穿线 | `0.22 ATR` | 小影线或市场噪声不会立即否定趋势 |
| 实体穿线起点 | `-0.10 ATR` | 低于此值记为实体已穿线 |
| 严重实体穿线 | `-0.35 ATR` | 对完整性施加较大惩罚 |
| 最长连续实体穿线 | 2 根 | 达到 3 根时不进入最终结果 |

单根实体穿越可以保留；连续穿越从第二根开始快速减分。

## 6. 识别有效触点

算法对 `gap` 做居中平滑，再在 `-gap` 上找局部峰值。上涨时相当于找回调低点，
下跌时相当于找反弹高点。

| 参数 | 当前值 | 含义 |
| --- | ---: | --- |
| 平滑窗口 | 短结构 3，其他 5 | 降低单根 K 线噪声 |
| 独立触点最小间隔 | `max(2, length // 18)` | 避免连续几天贴线被重复计数 |
| 最低 prominence | `0.12 ATR` | 触点必须是可辨认的局部挑战 |
| 最远触线距离 | `0.75 ATR` | 超过此距离不算触线 |
| 触点后观察长度 | 7～24 根 | 判断价格是否从趋势线处被拒绝 |
| 保持未严重破坏 | 大于 `-0.85 ATR` | 严重跌破/升破后不算高质量拒绝 |

首尾区域会额外寻找一次最接近趋势线的位置，因为峰值算法不会把序列端点当作峰值。

触点数量的基础分不是线性的：

```text
0、1、2、3、4、5次及以上
0.00, 0.12, 0.43, 0.73, 0.88, 1.00
```

第三个独立触点价值最大，更多触点继续加分但边际收益递减。

触点后的拒绝质量综合：

- 之后价格离开趋势线的幅度；
- 触点本身的 prominence；
- 后续是否保持在线的正确一侧；
- 轻微假突破后是否收回。

最新端点没有足够后续 K 线时可以记为触点，但不会提前得到完整拒绝分。

## 7. 衡量触点是否集中在首尾

算法统一计算四个指标：

| 字段 | 范围 | 含义 |
| --- | ---: | --- |
| `event_span` | 0～1 | 首末触点覆盖拟合窗口的比例 |
| `max_touch_gap` | 0～1 | 最大相邻触点空白占首末触点跨度的比例 |
| `touch_distribution` | 0～1 | 最大空白和四段时间覆盖的综合质量 |
| `interior_touches` | 非负整数 | 位于拟合窗口中部 20%～80% 的触点数 |

`touch_distribution` 的计算中，最大空白占 65%，四个时间分箱覆盖占 35%：

```text
gap_score = clip((0.78 - max_touch_gap) / 0.38, 0, 1)
bin_score = clip((occupied_bins - 1) / 3, 0, 1)
touch_distribution = 0.65 * gap_score + 0.35 * bin_score
```

触点分布已经参与各层基础评分。本版本再增加统一的连续减分：

```text
quality = clip(touch_distribution / 0.55, 0, 1)
weakness = (1 - quality) ^ 1.5
最终层级分 = 原层级分 * (1 - 最大减分 * weakness)
```

| 层级 | 最大减分 | 原因 |
| --- | ---: | --- |
| 长期 | 16% | 长结构理应覆盖更多市场阶段 |
| 中期 | 14% | 需要明显回踩，但允许阶段性悬空 |
| 短期 | 8% | 样本较少，惩罚最轻但不再豁免 |

分布达到 0.55 后不再额外减分。此前长期和部分中期使用
`max_touch_gap <= 0.80` 的硬淘汰，本版本取消该断点；越集中只会连续减更多分。

`event_span` 仍作为最低结构证据：长期至少 0.38，中短期至少 0.28。
它衡量首末触点是否覆盖候选窗口，与“首尾之间是否悬空”不是同一个问题。

## 8. 计算长、中、短期分数

层级按首末有效触点跨度 `structure_length` 划分，而不是按粗搜窗口长度划分：

```text
short_max = max(10, round(0.10 * N))
long_min  = max(short_max + 1, round(N / 3))
```

N=150 时，短期为 7～15 根，中期为 16～49 根，长期为 50 根以上。

### 8.1 长期结构分

```text
17% 锚点单侧完整性
18% 实体完整性
11% 触点贴近度
22% 触点数量、跨度和分布综合分
14% 触点后拒绝质量
10% 触点分布
 3% 方向效率
 5% 斜率相对 ATR 的强度
```

默认门槛 55 分；至少 3 个触点，`event_span >= 0.38`，
方向漂移 `drift_t >= 0.55`。

### 8.2 中期趋势分

```text
17% 锚点单侧完整性
18% 实体完整性
12% 触点贴近度
20% 触点综合分
12% 拒绝质量
 9% 触点分布
 6% 方向效率
 4% 斜率强度
 2% 方向显著性
```

默认门槛 70 分；至少 2 个触点，`event_span >= 0.28`，
`drift_t >= 0.65`。只有两个触点时门槛额外提高 4 分。

拟合长度不超过 30 根且终点在最近 12 根的中期反转结构，门槛可降至 66 分。
后续锚点没有突破且距线不超过 1.25 ATR 的中期线，也可参考短期推进分；
这只影响候选评分，不再决定状态和绘图是否延伸。

### 8.3 短期推进分

短期分提高方向效率和斜率权重：

```text
16% 锚点完整性       16% 实体完整性
14% 触点贴近度       14% 方向效率
12% 斜率强度          8% 方向显著性
12% 触点综合分        4% 拒绝质量
 2% 触点跨度          2% 触点分布
```

默认门槛 64 分；至少 2 个触点，`event_span >= 0.28`，
`drift_t >= 0.85`，拟合终点必须在最近 10 根。
只有两个触点时门槛提高 3 分；结构短于 10 根时再提高 7 分。

字段说明：

- `efficiency`：净方向移动除以价格总路径，越接近 1 越单向；
- `slope_strength`：整段斜率移动折算成 ATR，约 3 ATR 达到满值；
- `drift_t`：方向收益的类 t 值，越大表示方向更稳定；
- `proximity`：有效触点到线的中位距离转换成的 0～1 分；
- `integrity`：锚点大部分位于正确一侧的程度；
- `body_integrity`：K 线实体没有持续穿线的程度。

## 9. 去重和显示噪音过滤

同方向候选若时间高度重合且几何距离很近，会被视为重复线。比较时在共享区间最多抽样
7 个位置，并用当地 ATR 标准化距离。

主要重复条件：

- 常规共线：共享至少 40%，距离中位数不超过 0.55 ATR；
- 高度嵌套：共享至少 85%，距离中位数不超过 1.05 ATR；
- 首末日期分别相差不超过 15 根时，使用较宽的边界条件；
- 斜率累计分歧分别限制在 1.25、2.00 或 3.00 ATR。

同一重复组中，距离最高分 10 分以内时优先保留触点跨度更长、结束更晚的线。

### 9.1 趋势族合并

精确去重之后，算法还会把“并非重合，但在解释同一段行情”的同方向线归入一个趋势族。
与族内主线同时满足以下条件时，视为同族：

- 与较短结构的时间重合比例至少 55%；
- 共享区间内线间距离中位数不超过 `2.00 ATR`；
- 线间距离 80% 分位数不超过 `3.00 ATR`。

趋势族采用主线锚定方式，不做传递式无限合并。每条候选只与各族主线比较，并加入亲和度
最高的一族，避免 A 接近 B、B 接近 C 就把相距很远的 A 和 C 强行合并。

每个趋势族先保留一条主趋势线。主线首先按是否仍未结束排序；在同一状态下使用：

```text
主线质量 =
    tier_score
  + 6 * touch_distribution
  + 4 * min(1, structure_length / N)
```

因此当前仍有效的线优先于已结束线；之后综合最终评分、触点分布和结构跨度。

每族至多再保留一条阶段变化线。候选必须同时满足：

- 评分与主线相比最多低 8 分；
- 至少有 2 个主线无法解释的独立触点；
- 与主线距离超过 `0.80 ATR` 的连续区间至少 8 根；
- 相对主线的斜率差至少 25%。

候选触点位于主线时间范围之外，或该触点处两条线距离超过 `0.75 ATR`，都算主线无法
解释的新增触点。多个阶段候选同时合格时，依次优先新增触点更多、连续分离更久、
斜率差更明显、评分更高者。

趋势族合并后才应用全图数量限制：最终最多展示 6 条，其中长期最多 3 条、中期最多
4 条、短期最多 2 条。不同时间阶段或几何距离明显不同的同方向线不会仅因方向相同被合并。

最后还有两个纯显示噪音过滤：

1. 若结构内最高最低价差不超过 10%，且趋势线自身变动不超过 2.5%，视为过平；
2. 若一条低分反向线首尾都被两条更高分同向线包住，视为夹在主结构中的噪音。

## 10. 用收盘价判断趋势状态

状态不再使用包含开盘价和影线的拟合锚点，而使用收盘价到趋势线的距离：

```text
close_gap = d * (Close - line) / ATR
```

状态只有三种，但“已结束”可以由反向突破或顺方向持续加速触发：

| 状态 | 判定 |
| --- | --- |
| `trending` / 趋势中 | 尚未确认突破，最新 `close_gap > 0.50` |
| `challenging` / 挑战中 | 尚未确认突破，最新 `close_gap <= 0.50` |
| `broken` / 已结束 | 已满足反向突破确认，或旧趋势被持续加速行情替代 |

突破满足任一条件：

- 连续两根收盘都穿到错误一侧至少 `0.30 ATR`；
- 任意一根收盘严重穿越至少 `0.80 ATR`。

一次中等穿越但下一根收回，只会暂时显示“挑战中”。确认突破后记录
`break_index`，用于停止趋势线延伸。

顺趋势方向远离趋势线本身不等于突破，但可能表示市场已经进入斜率更快的新趋势。
持续加速结束需要同时满足：

- 收盘首次远离旧趋势线至少 `4.00 ATR`；
- 后面至少已有 3 根 K 线可用于确认；
- 此后直到当前都没有重新回到旧趋势线 `1.50 ATR` 内。

满足后从首次达到 `4.00 ATR` 的位置停止旧趋势线，记录 `acceleration_index`。
如果后来重新回到 `1.50 ATR` 内，旧趋势线仍保留。例如 GDX 的 3 月下跌压力线在
2026-06-05 首次远离约 4.79 ATR，之后未返回，因此在该日结束；MU 的 4 月上涨支撑线
虽然曾远离 4～8 ATR，但 7 月重新靠近，最新约 1.20 ATR，因此继续延长。

## 11. 三段绘图

三段都来自同一次最新 N 根窗口分析，不会用另一次历史窗口重新拟合：

1. **形成段**：首个有效触点到达到最低触点要求的位置，使用较浅线条；
2. **确认段**：形成位置到最后有效触点，使用该层级正常样式；
3. **延伸段**：最后触点到最新 K 线或趋势结束位置，颜色稍浅。

长期达到第 3 个触点视为结构形成；中短期达到第 2 个触点视为形成。
“形成”只描述当前窗口中这条最终趋势线的触点顺序，不代表当时已经产生可回测交易信号。

未结束的线延伸到最新 K 线。已结束线延伸到反向突破或持续加速的确认位置后停止。

线型只由最终评分决定：

- `tier_score >= 75`：实线；
- `tier_score < 75`：虚线。

形成段、确认段和延伸段保持相同线型，只用较温和的颜色深浅区分。不同趋势线按评分
顺序分配蓝、红、青绿、紫、橙、青、洋红、绿色等高区分度颜色，方向不再绑定颜色。

## 12. 输出字段

| 字段 | 含义 |
| --- | --- |
| `start_index` | 第一个有效触点 |
| `formation_end_index` | 达到最低触点要求的位置 |
| `end_index` | 最后一个有效触点 |
| `projection_end_index` | 最新 K 线或趋势结束位置 |
| `break_index` | 确认突破位置，未突破时为 `null` |
| `acceleration_index` | 持续加速最初达到 4 ATR 的位置 |
| `termination_index` | 实际绘图结束位置 |
| `termination_confirmed_index` | 突破或持续加速完成确认的位置 |
| `end_reason` | `break`、`acceleration` 或 `null` |
| `fit_start_index`, `fit_end_index` | 搜索拟合时使用的原始窗口 |
| `touch_indices` | 全部有效触点位置 |
| `score` | 通用长期结构公式分 |
| `tier_score` | 加入所属层级规则和分布减分后的最终分 |
| `distribution_penalty_factor` | 分布减分乘数，1 表示没有额外减分 |
| `current_close_gap` | 最新收盘到趋势线的 ATR 方向距离 |
| `previous_close_gap` | 前一根收盘到同一条当前趋势线的 ATR 方向距离 |
| `age` | 最后触点距最新 K 线的根数 |
| `active` | 尚未确认突破时为 true |
| `parent_id` | 包含该线的最近同方向上级结构 |
| `family_id` | 所属趋势族，使用该族主线 ID |
| `family_role` | `primary`、`stage` 或 `standalone` |

## 13. 修改和验证流程

每次调整评分、阈值、状态或绘图字段时应同时完成：

1. 修改前用 `scripts/snapshot_trendline_results.py` 保存全标的识别快照；
2. 修改代码和单元测试；
3. 用同一批数据生成修改后快照；
4. 比较中长期保留率、数量、评分变化和新增/消失原因；
5. 运行合成案例、人工标注案例和全数据库审计；
6. 更新算法版本、本文和 README。

常用命令：

```bash
python3 -m unittest tests.test_trendline_analysis -v
python3 scripts/validate_trendline_algorithm.py
python3 scripts/validate_trendline_algorithm.py --all-symbols
python3 scripts/snapshot_trendline_results.py output.json
```
