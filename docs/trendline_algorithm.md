# 智能直线趋势线算法

本文说明项目当前使用的直线趋势线算法。实现位于
`services/trendline_analysis_service.py`，不依赖 `algorithm/` 目录中的外部原型文件。

## 1. 识别目标

算法输入最近 N 根 OHLCV K 线，默认 N=150，输出：

- 上涨行情中位于价格下方的支撑趋势线；
- 下跌行情中位于价格上方的压力趋势线；
- 当前短期推进线、历史或当前中期趋势线、长期结构线；
- 每条线的分数、触线次数、触点分布、状态和可绘制坐标。

趋势线是单侧价格包络，不是穿过全部收盘价的回归中轴。上涨过程中价格可以大幅远离支撑线，但回调低点应当多次靠近趋势线；下跌压力线完全对称。

## 2. 价格与波动标准化

真实波幅定义为：

```text
TR = max(High-Low, abs(High-PreviousClose), abs(Low-PreviousClose))
```

算法使用 14 根滚动中位数平滑 TR。价格到趋势线的距离均除以该位置的 ATR，因此 0.3 的距离表示 0.3 ATR，而不是固定价格单位。

上涨支撑参考点以实体下沿为主：

```text
body_edge = min(Open, Close)
wick_mid = (Low + body_edge) / 2
anchor_up = 0.75 * body_edge + 0.25 * wick_mid
```

下跌压力参考点使用实体上沿和上影线中点的对称公式。

## 3. 候选线拟合

候选直线为 `price = intercept + slope * candle_index`。上涨线要求正斜率，下跌线要求负斜率。

每个候选区间最多抽样 28 个参考点，计算两两斜率并保留方向正确的斜率。基础截距分位数为 3%、7%、13%、20%，下跌压力线使用对称高分位。覆盖率、实体完整性、严重突破率和低分位距离用于批量粗筛；初筛分最高的 5 个组合执行完整评分。

N=150 时粗搜索主要覆盖 7、10、15、22、32、45、59、63、86、116 和 150 根窗口。短窗口使用较密的结束日期，长窗口使用较疏步长。粗搜索结果按以下维度分组保留：

- 上涨或下跌方向；
- 短、中、长期层级；
- 起点所在的五分区；
- 终点所在的五分区。

这样近期强趋势不会挤掉较早但清晰的结构。保留候选再对起止点做约正负 6 根的局部精搜。短期线另行搜索最近 10 个可能终点，并外推到最新 K 线验证。

## 4. 触线、拒绝与分布

统一方向距离为：

```text
gap = direction * (anchor - line) / ATR
```

其中上涨 `direction=1`，下跌 `direction=-1`。`gap` 为正表示价格处于趋势线正确一侧，为负表示穿线。

算法在每个候选线的 ATR 标准化距离序列上识别局部挑战点：

- 小于 36 根使用 3 根平滑窗口，否则使用 5 根平滑窗口；
- 最小独立触点间隔为 `max(2, length // 18)`；
- 局部挑战点 prominence 不低于 0.12 ATR；
- 平滑距离不高于0.75 ATR才视为挑战；
- 首尾区域单独检测，避免峰值算法漏掉边界触点。

触线次数不是线性计分。计入跨度和分布修正前，0～5次及以上的基础分依次为：

```text
0.00, 0.12, 0.43, 0.73, 0.88, 1.00
```

因此两点只提供较弱证据，第三个独立触点会明显提高可信度，第四、第五个触点继续增加但边际收益递减。

拒绝质量综合未来窗口内离开趋势线的幅度、枢轴 prominence、假突破后收复和后续严重破坏。最新端点尚无足够后续 K 线时，只计为挑战，不提前认定拒绝成功。

## 5. 防止首尾桥接

仅有首尾触点的直线很容易把两个独立趋势错误连接起来。算法增加两个指标：

- `max_touch_gap`：相邻触点之间最大空白占首末触点跨度的比例；
- `touch_distribution`：结合最大空白和四个时间分箱覆盖率得到的分布分。

长期结构要求至少 3 个触点，且 `max_touch_gap <= 0.80`。三个及以上触点的中期线也要求 `max_touch_gap <= 0.80` 且分布分至少0.15。这样首尾两侧各有少量触点、中间大段悬空的候选会被过滤。

该规则不会机械要求每一段价格都贴线。脉冲上涨远离支撑或快速下跌远离压力仍然允许，只要整段结构中存在足够的独立回测证据。

### 5.1 实体穿越约束

影线可以越过趋势线，但实体被连续穿越通常表示该线不再构成真实支撑或压力。算法使用实体边缘到趋势线的 ATR 距离：

```text
上涨：body_gap = (min(Open, Close) - line) / ATR
下跌：body_gap = (line - max(Open, Close)) / ATR
```

- `body_gap < -0.10` 记为实体穿越；
- `body_gap < -0.35` 记为严重实体穿越；
- 单日穿越允许保留，单根穿入深度最多按0.80 ATR计罚，孤立严重穿越使用较低权重；
- 连续穿越从第 2 根开始指数降分；
- 最长连续实体穿越达到 3 根时不进入最终结果。

连续穿越仍保持高惩罚和硬过滤。该非对称处理允许单根跳空异常，同时继续排除 XAU/USD 一类连续穿过大量实体的直线。

## 6. 周期层级

边界随 N 动态计算：

```text
short_max = max(10, round(0.10 * N))
long_min = max(short_max + 1, round(N / 3))
```

N=150 时：

| 层级 | 长度 |
| --- | ---: |
| 短期 | 7～15 |
| 中期 | 16～49 |
| 长期 | 50～150 |

层级按首末有效触点的跨度划分，而不是按粗搜索窗口长度划分。该设计避免“拟合了 60 根、实际只有最后 10 根形成支撑”的候选冒充长期线。历史短波段如果达到 16 根，会作为中期线保留；短期层至少需要 7 根有效触点跨度。

## 7. 三类评分

### 7.1 长期结构分

长期结构分的权重为：

```text
17% 单侧包络完整性
18% 实体完整性
11% 枢轴贴近度
22% 多触点证据
14% 触线后拒绝
10% 触点分布
 3% 方向效率
 5% 斜率相对 ATR 的强度
```

长度置信度和方向漂移门控采用平滑函数，不会在单个参数边界突然跳变。默认门槛为 55 分，并额外要求：

- 至少 3 次独立触线；
- 首末触点覆盖至少 38% 区间；
- 最大无触点区间不超过触点跨度的 80%；
- 方向漂移 t 值不低于 0.55。

### 7.2 中期趋势分

中期分兼顾结构确认和方向推进：

```text
17% 单侧包络完整性
18% 实体完整性
12% 枢轴贴近度
20% 多触点证据
12% 拒绝质量
 9% 触点分布
 6% 方向效率
 4% 斜率强度
 2% 方向显著性
```

默认门槛为 70 分，至少2次触线、触点跨度至少28%、方向漂移 t 值至少0.65。只有2个触点时门槛提高4分。

中期分额外加入最多15分的阶梯节奏奖励。它综合枢轴依次抬高/降低、触线后拒绝、方向效率、方向漂移、触点分布和枢轴对齐度，用于奖励“推进、回踩、再推进”的行情。

### 7.3 短期推进分

短期分提高方向效率、斜率和实时状态的权重，同时给实体完整性 16%、多触点证据 12%。默认门槛为 64 分，并要求：

- 至少 2 次触线，只有 2 次时门槛提高 3 分；
- 少于 10 根的极短线门槛提高 7 分；
- 方向漂移 t 值至少 0.85；
- 拟合终点位于最近 10 根；
- 外推后未突破时可延伸到当前，已经突破时只保留最后触点之前的历史有效段。

16～30 根、拟合终点在最近 12 根内的中期反转线，会同时参考短期推进分，筛选门槛降至 66 分。即使拟合已经结束，只要后续未突破且当前距线不超过 1.25 ATR，也按这一规则评估，以保留仍有效的中期支撑或压力。

## 8. 跨层级统一去重

所有通过门槛的长、中、短期线一起比较，不再只在同层级按日期区间去重。

两条同方向线需先满足以下时间条件之一：

- 首末有效触点分别相差不超过 15 根；
- 两条线共享区间达到较短结构的 40%。

随后在共享区间抽样最多 7 个位置，以 ATR 标准化后同时要求：

```text
常规共线：
  共享比例         >= 40%
  距离中位数       <= 0.55 ATR
  距离80%分位数    <= 0.90 ATR
  斜率累计分歧     <= 1.25 ATR

高度嵌套：
  共享比例         >= 85%
  距离中位数       <= 1.05 ATR
  距离70%分位数    <= 1.50 ATR
  斜率累计分歧     <= 2.00 ATR
```

使用距离分位数而不是最大距离，避免单个端点噪声阻止明显重复线合并。时间前后大部分错开、仅在边界相接的匀速和加速阶段不会合并。

重复关系使用连通分组统一处理。每组先找到最高层级分，分数与最高分相差不超过 10 分的候选中优先保留有效触点跨度更长、终点更新的一条；差距更大时保留明显更高质量的候选。每层仍有独立上限，所有层级合计最多输出 6 条线。

## 9. 当前状态与绘图

每条线默认只绘制首个有效触点到最后一个有效触点。之后按当前状态决定是否外推：

- `broken`：后续有效穿越错误一侧，保留历史有效段但不外推；
- `valid`：未破坏且当前距线在 0.50～1.25 ATR；
- `challenging`：未破坏且当前距离不超过 0.50 ATR。

当前距线超过 1.25 ATR 时视为历史结构，即使尚未发生方向性突破也不延伸。历史线距今76～105根时附加6分门槛，超过105根附加8分且至少需要80分。

长期使用点状线，中期使用虚线，短期使用实线。同层级多条线由前端分配不同颜色。最终仍最多6条，其中长期最多3条、中期最多4条、短期最多2条。后端返回触点分布、实体穿越、有效触点区间和当前状态等解释指标。

## 10. 防止未来函数

- 分析只使用调用时可见的最近 N 根 K 线；
- 拒绝质量只使用候选触点之后、分析终点之前已经出现的数据；
- 最新触点没有未来 K 线时不能记为拒绝成功；
- 短期线结束后的 K 线只用于当下的外推有效性验证；
- 历史回测必须在每个历史日期重新截断数据后计算。

## 11. 验证体系

单元测试覆盖：

- 150 根窗口的 15/50 周期边界；
- 多次均匀触线相对两点桥接的加分；
- 连续实体穿越相对单日穿越的大幅扣分；
- 三个以上触点对中期分的提升；
- 跨窗口几何重复判断；
- 首尾桥接线不能成为整段长期结构。
- 序列化只绘制首末有效触点，当前有效线才延伸到最新日期；
- 低分历史线随距今时间增加被隐藏。

完整验证脚本包含：

- 多触点稳定上涨；
- 只有头尾支撑、中间悬空的桥接压力样本；
- 上涨转下跌的趋势切换；
- 随机均值回归横盘；
- USDINDEX、SPX、US10Y、MU、GDX 的人工标注真实区间。

真实案例同时检查同方向覆盖率和日期区间 IoU，避免用一条过长趋势线宽泛覆盖目标区间来冒充命中。每组最终结果还会再次检查是否存在几何重复对。

运行：

```bash
python3 -m unittest tests.test_trendline_analysis -v
python3 scripts/validate_trendline_algorithm.py
python3 scripts/validate_trendline_algorithm.py --all-symbols
```

## 12. 后续校准建议

当前参数针对项目数据库中的日线和默认 150 根窗口调校。扩展到不同资产、分钟线或更长窗口时，应按资产类型和波动状态分别校准：

- 使用块自助法构造保留波动聚集的无趋势样本；
- 统计完整多窗口搜索后每层最高分的 95% 或 99% 分位数；
- 以未来延续、突破、最大回撤和信号寿命评估有效性；
- 对不同周期分别设定 ATR 容差、漂移门槛和结果数量上限。

成交量目前保留在输入和输出链路中，尚未进入评分。后续可增加缩量回踩、放量突破和成交密集区确认，但应独立做样本外验证。
