# 公司行动、标的身份与价格口径

本文记录 2026-08-02 的全标的公司行动审计，以及行情展示和历史回测采用的统一口径。

## 1. 设计结论

数据库永久保存供应商返回的原始 K 线和独立公司行动，不把历史 K 线改写成某一次复权
结果。这样可以保留审计依据、支持同一标的多次拆股/分红，并允许展示与回测按用途选择
复权方式。

- `daily_prices.price_basis` 明确记录 raw、拆股复权、全复权或未知口径。
- 只有 `raw` 数据可以应用本地公司行动因子；未知或已经复权的数据保持原样并警告，防止
  FNGS 等历史来源发生二次复权。
- `corporate_actions` 保存事件级字段；`corporate_action_legs` 保存 subject、source、
  target、acquiree、acquirer 等参与方。
- `instrument_symbols` 与 `instrument_identifiers` 用 CUSIP/ISIN 记录代码沿革；
  `symbols.alpaca_asset_id/cusip/isin` 保存当前身份。

### MAGS 身份冲突

接口会按代码返回 2021 年旧公司 `MAGS → SNT`，但当前 MAGS ETF 是 2023 年
`BIGT → MAGS`，两者 CUSIP 不同。系统不再仅按字符串代码归属事件，而是结合实际首根
本地 K 线、事件参与方角色及 CUSIP/ISIN 过滤。旧公司的事件不会阻断当前 MAGS ETF；
当前更名和其后分红仍会进入审计快照。

阶段返回缺失字段详情，不会假设除息日即时到账。

## 3. 行情展示算法

- `raw`：直接展示入库 OHLCV。
- `split`：每个事件日前的 OHLC 除以累计拆股比例，成交量乘累计比例。
- `all`：在拆股基础上，对每个除息日前历史价格乘
  `(前一有效收盘价 - 同日现金分红总额) / 前一有效收盘价`。
- 多次事件按日期累计；同日多笔现金分红先汇总。
- 日线以上周期先复权再聚合；分钟周期先按交易日聚合，再应用相同的日级事件因子。

行情展示的用途口径如下：

- 行情总览中的 MA、EMA、ATR、RATR、WTME 等标准指标固定使用 `all` 前复权日线；总览读取
  只使用 SQLite 已保存的公司行动，不会因页面刷新而发起外部请求。响应以
  `indicator_standard_price_basis=all_adjusted` 和 `indicator_action_source=stored_only`
  明示该约束。尚未落库的公司行动自然尚未进入计算，需由既有同步/核验流程补齐。
- 标的详情默认选择 `all`，也允许用户切换 `split` 或 `raw`。K 线和指标始终使用同一选择，
  服务端先完成复权、聚合和指标计算，浏览器只绘制返回的序列。
- 若入库数据不是明确的 `raw`，系统保持原样并返回警告；不会为了满足“前复权”标签而对
  口径不明的数据二次处理。

## 4. 历史回测算法

回测保留两套用途明确的数据视图：

1. 原始 K 线用于订单参考价、成交、每日盯市和账户权益。
2. 截至当前回测日可知的复权历史用于 MA、EMA、ATR 等技术指标，防止拆股/除息制造
   虚假跳变，同时不把未来公司行动提前带入过去信号。

除息日开盘前按持仓确认应收，支付日转现金；拆股日开盘前调整数量和每股成本。更名为
无经济影响事件。尚未建模或关键字段不完整的行动会停止回测，不生成可能错误的收益曲线。
核验下界是本次运行实际使用的指标预热首日，而不是无条件追溯标的全部历史；因此旧事件
只有在仍会影响本次 MA/EMA/ATR 输入或落入交易区间时才参与预检。
