目标仓位与风险

历史成交模拟

VOLAT(T) × 3 × √(n/252) 估算无杠杆压力跌幅；动态单标的杠杆向下保留 1 位小数，并限制在 1.0 至 max_l。自动再平衡仅控制杠杆变化额外触发的调仓；关闭后新杠杆仍用于策略下一次主动下单。x 与 max_l 只是计算参数，不构成爆仓保证。

实际敞口 = 策略目标仓位 × 整体杠杆 × 单标的杠杆 × 策略特殊杠杆；暂不计融资利息。账户权益不大于 0 时按分钟行情强制平仓并标记爆仓。手续费按每笔 max(股数×每股手续费, 最低手续费) 计算；买卖双边收取。关闭详细日志后不会生成、实时传输或持久化策略审计日志，但权益曲线、成交和指标不受影响。

变量与布尔值
price 是当前决策价；position 是当前仓位比例（0 到 1）；布尔值使用 true、false。

          
历史行情
open(n)、high(n)、low(n)、close(n)、volume(n)。参数 n 表示向前第 n 根已完成日线，例如 close(1)。

          
单值指标
ma(n)、ema(n)、atr(n)、volat(n)、ratr(n)、rsi(n)。volat(n) 返回 n 期对数收益率按 252 个交易日年化的历史波动率（%）；r_square(n) 返回前 n 根完整 K 线加当前价格（共 n+1 点）的加权对数价格趋势 R²，默认窗口为 25。

          
WTME 与急跌过滤
wtme(n, h) 或 wtme(n, h, epsilon)；默认示例 wtme(40, 15, 0.00000001)。rapid_drop(n, threshold_percent) 命中急跌返回 1，否则返回 0。

          
MACD
macd_line(fast, slow) 返回 DIF；macd_signal(fast, slow, signal) 返回 DEA；macd_hist(fast, slow, signal) 返回未加倍柱状值 DIF − DEA。默认参数为 12、26、9。

          
运算与执行时间
支持 + - * /、> >= < <= = !=、AND OR NOT 和括号。执行时间可填 OPEN、CLOSE 或美东时间 HH:MM。

          
示例
rsi(14) < 30 AND price > ma(20)
macd_hist(12, 26, 9) > 0 AND macd_line(12, 26) > macd_signal(12, 26, 9)
wtme(40, 15) >= 0 AND rapid_drop(5, 5) = 0
r_square(25) >= 0.8 AND price > ma(20)
price < close(1) - 2 * atr(14)
